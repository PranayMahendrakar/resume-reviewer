# 📄 Resume and Cover Letter Reviewer

**AI-Powered Job Application Feedback**

Author: Pranay M

## Overview

Provides comprehensive feedback on resumes and cover letters with optimization suggestions.

## Features

- Resume review with scoring
- Cover letter analysis
- Job-specific optimization
- Bullet point generation
- Cover letter drafting

## Installation

```bash
ollama pull llama3.2
pip install -r requirements.txt
python main.py
```
